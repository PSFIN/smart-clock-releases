# Smart Clock — desktop app downloads

Installers for the Smart Clock time-tracking app (PSFIN Solutions). Download the latest from **Releases**:

- **Windows:** `Smart-Clock-Setup-<version>.exe`
- **Mac with Apple chip (M1–M4):** `Smart-Clock-<version>-arm64.dmg`
- **Mac with Intel chip:** `Smart-Clock-<version>-x64.dmg`

You need a Smart Clock account from your administrator to sign in. The app updates itself (Windows) or tells you when a new version is ready (Mac).
